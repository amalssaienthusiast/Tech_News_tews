# pip-tools constraints file.
#
# This file pins known-good versions of dependencies that have historically
# caused issues or have known CVEs at their minimum-pinned versions in
# requirements.txt. It is NOT a complete lockfile — generate one with:
#
#     pip-compile requirements.txt -o requirements.lock
#     pip-compile requirements-dev.txt -o requirements-dev.lock
#
# Then install with:
#
#     pip install -r requirements.lock
#
# The pins below are upper-bound safety rails: they prevent pip from
# resolving to a known-broken or known-vulnerable version, while still
# allowing patch-level updates.
